| 2.0 | 2026-10-24 | Rebuilt in the standard agent format (Inputs, Steps 0–6, Budget, Guardrails, Runtime notes); file renamed `soc-analyst.agent.md`. Added: LIVE/OFFLINE mode; scope routing to other agents; E# evidence log with OK/NO_RESULTS/FAILED/NOT_RUN; benign-vs-malicious readings with the deciding evidence; symmetric evidence bar with UNDETERMINED disposition; six fixed dispositions with human confirmation; Mitigated finding status for blocked activity; reputation age for stale indicators; REQUIRES APPROVAL wording for containment; never fetch suspected malicious URLs/files; embedded-instruction detection in alert content; JSON handoff; budget with fail-to-escalate. Ideas informed by a review of public SOC-triage projects and a published phishing-triage study; wording is original. |
