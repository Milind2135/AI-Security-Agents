# team-manager changelog (formerly team-lead)

| Version | Date | Change |
|---|---|---|
| 2.1 | 2026-11-20 | Roster: `soc-analyst` now also hunts (`mode: hunt`). Routing row 9 (hunting in our own telemetry) goes to `soc-analyst` hunt mode instead of a human threat-hunting team; follow-on rules pass affected-and-exposed reports as `vuln:` and escalated triage reports as `escalation:`; the threat-hunting human team is removed from the people list and the route values. Tests updated. |
| 2.0 | 2026-11-17 | **Renamed** `team-lead` → `team-manager` (file, name, markers, JSON `agent` field, entries, tests) before release. Full rebuild in the portable standard format (frontmatter, core rules in the file, runtime-neutral tool roles, Inputs, Steps 0–6, output contract, JSON, Budget, Guardrails in three groups, Runtime notes, usage card, Claude Code and Codex entries). **Roster** corrected to the six live agents (vm-triage, vulnerability-hunt, soc-analyst, cloud-security-analyst, threat-modeler, threat-intel-analyst); removed roles route to **human teams** (threat hunting / IR, detection / SOC engineering, DevSecOps / platform, system or risk owner, IR lead). **13-row first-match routing table** plus follow-on rules. **Modes:** `plan` (default; routed plan with ready-to-copy prompts and `<JSON from step N>` handoffs), `run` (only with an agent-call tool; plan → `approve plan` → run; agent pauses are relayed to the human, never answered) and **combine** (`reports:` → report register, source-tagged findings, conflicts shown for human review, **grounding check** that removes anything not found in any report, confidence capped by the weakest report). Stop rules: at most 5 agent steps, 2 re-plans. Removed the Elastic-specific rules and the list of built-in helper names. Not adopted: confidence-based auto-approval, alert polling, response actions. 9 golden tests in `tests/team-lead/` with synthetic combine fixtures. |
| 1.1 | 2026-10-24 | Roster changed from seven to eight agents: `vulnerability-analyst` replaced by `vm-triage` (public CVE intelligence) and `vulnerability-hunt` (are we affected, exposure, urgency, tickets). Added a vulnerability routing example: vm-triage → vulnerability-hunt → threat-hunter (affected and exposed only) → risk-analyst (business impact only). No other changes; full restructure into the standard format is pending. |
